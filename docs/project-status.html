2. 知識蒸留の全体図

同じ画像を3経路へ入力します。人手GTが正解を教え、SAM 3が対象領域、DINOv3が一般的な視覚構造を補助的に教えます。

人手教師・通常学習 SAM 3領域教師 DINOv3特徴教師 Student更新

E003: SAM 3 logit蒸留

L = LBCE + LDice + 0.5 × Llogit-KD

SAM 3のinstance maskをbinary maskへ統合し、前景0.99・背景0.01相当のpseudo-logitへ変換。confidenceの低い領域はKD対象から外します。

E004b: DINOv3 feature蒸留

L = LBCE + LDice + 0.25 × Lcosine-feature

Studentのencoder_s16（48 channel）を学習用1×1 projectionで384 channelへ写し、DINOv3 patch featureとのcosine distanceを最小化します。

3. 教師モデルは何を、どこで教えるか

教師入力Studentへ渡す知識実装上の場所Edge推論時
人手GT mask 画像と対になるbinary mask 糸／亀裂の正解領域。BCE + Diceで直接学習 data/*/manifest.csv 不要
SAM 3 画像 + text prompt 対象の形状・領域、instance score由来confidence create-sam3-teacher-cache → teacher_cache/ 搭載しない
DINOv3 ViT-S/16 画像 形状・質感・部品構造・領域類似性を持つdense feature create-dinov3-feature-cache → teacher_cache/ 搭載しない
TeacherはStudentの各epochで毎回動かしません。GPU環境で一度cacheを作り、そのcacheを固定してLoss・Student構造・seedを比較します。 これにより、教師出力の変化を実験差へ混入させず、Foundation Modelの重い推論コストも学習ループから外せます。

4. 軽量Studentの構造

Feature projection

DINOv3蒸留時だけ使用。学習後は破棄するため、Edgeモデルのparameter数・latencyを増やしません。

Teacher cache

学習時だけ参照。ONNXには含まれず、Edge端末へコピーする必要もありません。

出力

binary semantic segmentation。個々の糸instance IDではなく、糸／亀裂領域か背景かを出力します。

5. 学習済みモデルをEdgeへ小型化するフロー

ONNX入力は正規化済みのfloat32 NCHW、batch 1固定です。letterbox・ImageNet正規化・sigmoid・thresholdはEdgeアプリ側で同じ条件を再現します。

  • SAM 3 teacherが細線を正しく拾うpromptと閾値

8. 最短の実行順序

  1. DeepCrackを準備しBaselineを学習
    python -m fm_to_edge_seg train configs\experiment\e001_deepcrack_baseline.yaml
  2. testとRobustnessを評価
    python -m fm_to_edge_seg evaluate-robustness ... --split test --device cuda
  3. SAM 3 / DINOv3のteacher cacheを別々に作る
    python -m fm_to_edge_seg create-sam3-teacher-cache ...
python -m fm_to_edge_seg create-dinov3-feature-cache ...
  4. E003 / E004を学習し、Baselineと同じsplitで比較
    python -m fm_to_edge_seg train configs\experiment\e003_sam3_text_logit_kd.yaml
python -m fm_to_edge_seg train configs\experiment\e004b_dinov3_feature_kd.yaml
  5. 採用StudentをFP32 ONNX → INT8へ変換
    python -m fm_to_edge_seg export-onnx ... student_fp32.onnx
python -m fm_to_edge_seg quantize-onnx ... student_fp32.onnx student_int8.onnx
  6. 同じCPU条件で精度・サイズ・速度を比較
    python -m fm_to_edge_seg evaluate-onnx ... --split test
python -m fm_to_edge_seg benchmark-onnx ... --threads 4 --runs 100
